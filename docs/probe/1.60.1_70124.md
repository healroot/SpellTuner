## What it settles (planner, 2026-10-01)

- **Macros (spec decision 12, T25 / T28 verified in part):** on Forever, `GetActionInfo(slot)` on a
  macro that casts a spell returns `("macro", <spell id>, "spell")` -- the **spell id itself**, not a
  macro index; `GetMacroSpell(<that id>)` answers nothing. A text-only macro returns `("macro", 2, "")`
  and `GetMacroInfo(2)` its name. `C_TooltipInfo.GetAction(slot)` gives type 25 (Macro) whose **first
  line is Spell-typed (`tooltipType = 1`) with `tooltipID` = the spell id** -- T28's first path resolves
  it. **Fix:** the owner-slot / `SetAction` path must take `GetActionInfo`'s id directly when its third
  return is `"spell"`, rather than passing it to `GetMacroSpell`. A real hover is still to be seen.
- **Status-bar readback (T13e / T17c):** a StatusBar handed a secret max reads it back **secret** --
  `MD.API.BAR_READS_MAX` stays `false`, the estimated party max (T17b) stands.
- **B1 confirmed:** in Bear Form `UnitPowerMax("player", 0)` = 395, plain.
- A shapeshift's mana cost is a **percent-of-base** row (`costPercent = 55`, `cost = 91`); rage costs
  are `type = 1` rows.
