SpellTuner: the refactor's UI mockups, M1 to M6

For the author to approve before waves 11-17 and wave C start (docs/PLAN-refactor-ux.md section 7). Each panel opens with what is wrong today (a short BEFORE note citing the review's U-number, docs/review/2026-09-30-project-review.md), then draws the new design at 1:1 in UI units with the approved Forever palette, fonts and sizes (SPEC-forever-ui.md section 4, docs/mockups/forever-ui.html). Section 8.1's answers are already applied: TBC gets the new UI, Review coaches a failed fight from the row menu's Coach anyway (no star, no shift-click), a placeholder's Turn on loads the module, dominated becomes beaten with a tooltip, each group keeps its own window size, both lines get the minimap button, and the replay's keys work only under the pointer and never in combat.

Forever frames use the level 10 druid from the approved mockup (364 mana). Review and the replay use the author's TBC dungeon recordings (Underbog), since decision 10 brings the same panes to TBC. The TBC Spells view uses the model's own numbers for a level 70 druid at +1150 healing and 9800 mana, computed with the offline harness. The web fonts stand in for Friz Quadrata and Arial Narrow. All the text drawn inside the UI is ASCII.
