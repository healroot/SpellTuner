SpellTuner after 0.16.5: styles, the clock, EllesmereUI, other classes (M7-M9)

Mockups for SPEC-next.md (task T86). Every panel names the spec section and the decision in section 9 it illustrates, plus the tasks that would build it. Geometry is the approved 0.16.5 window (860 x 560, 20-px header, 108-px nav, 172-px rail, 20-px rows); a style changes paint only (spec 5.1, principle 7), so the four style windows are pixel-for-pixel the same layout. All text inside a mocked frame is ASCII, as it will be in game.

Where numbers come from. Spell values (heal, absorb, cost, cast, cooldown) are the spells' own description texts from the talentsforever export (level 60 snapshot, CC BY 4.0, tools/.cache/talentsforever.json, the same texts R-classes ran the parser over), with no bonus healing. Per mana, per second and casts follow from them by the Book's rules. Marked illustrative: the character level, the learn levels, the mana pool, the clock times, the regen, and everything drawn inside EllesmereUI (its own frames, approximated from its source, 9.3.4). Classic art is a CSS approximation of Blizzard's files; the in-game screenshot after the art probe (T87) decides it.
